# OneBoard Local File Sort 1.0.0

First public OneBoard release, based on AI File Sorter v1.9.2.

## Highlights

- Local AI categorization and rename suggestions
- Review before apply, Dry Run, and Undo Last Run
- Independent OneBoard branding
- Cloud LLM providers and upstream network services disabled
- Windows x64 Standalone portable and installer packages

## Compatibility and packaging

- SSE4.2-capable x64 CPUs are supported on Windows.
- CA bundle staging is retained for the one-time, consent-based model download.
- Once the model is cached, analysis and file operations run locally without network access.
