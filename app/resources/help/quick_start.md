# OneBoard Local File Sort — Quick Start

1. Choose a small, disposable test folder first.
2. Select **Gemma 3 4B IT** and choose **Download Local Model** if it is not installed.
3. Scan the files and let local AI create suggestions.
4. Review every proposed category, folder, and filename.
5. Enable **Dry Run** if you want to verify the plan without changing files.
6. Confirm the reviewed changes to apply them.
7. Use **Undo Last Run** if necessary and if the filesystem has not changed externally.

The model runs locally after download. OneBoard does not upload your files or filenames to a OneBoard server. The initial model download requires internet access and several gigabytes of free disk space.
